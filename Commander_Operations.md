# How to operate with Loyalty in Commander 

Before operating for the first time make sure that everything is configured correctly. You can see the configuration required [here]().

### Index
 - [Pre-Authorization](#Pre-Authorization)
 - [Postpay](#PostPay)

 ## Pre-Authorization

1.	Select a pump
  <img width="415" height="150" alt="image" src="https://github.com/user-attachments/assets/fa92c36b-7aff-4374-96dc-60196b9b433f" />

2.	Enter the amount to pre-authorize
 <img width="514" height="396" alt="image" src="https://github.com/user-attachments/assets/4965f0a5-63e8-4aa1-a45c-f484aa5c3b17" />

3.	Select a fuel 

4.	Use the “Total” button and then press the "Loyalty" button
  
5. This will make the CSR prompt if the customer wants to redeem their points or apply a discount (If applicable)
<img width="190" height="108" alt="image" src="https://github.com/user-attachments/assets/90777e90-3550-4fea-ba53-aa9b8f20fd5a" />

6. If “yes” is selected then the attendant must swipe the loyalty card (Or what ever method used to identify the customer)
<img width="325" height="179" alt="image" src="https://github.com/user-attachments/assets/bae76e37-720c-4a03-886e-b32120789273" />

7. Then the screen will show the discount  and ask if they’d like to accept it (if applicable).
<img width="474" height="262" alt="image" src="https://github.com/user-attachments/assets/54b82800-8479-4d66-a9d4-70c3e2d4b355" />

8. The system will begin to process it
<img width="284" height="171" alt="image" src="https://github.com/user-attachments/assets/e76165da-d786-484e-8fb9-40e22b252123" />

9. If there was a discount applied, you will be able to observe it in the transaction details 
<img width="244" height="544" alt="image" src="https://github.com/user-attachments/assets/52c770d7-7d0d-4a1a-857d-c79251564c35" />

10. Then the attendant would proceed with the regular process by selecting the payment method and entering the remaining amount
 <img width="224" height="300" alt="image" src="https://github.com/user-attachments/assets/f5c2be21-8a68-47c2-8f80-1e8c3a2d8934" />
